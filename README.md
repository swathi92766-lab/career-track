# CareerTrack – Job Application Tracker

## About the Project
CareerTrack is an HTML5-based Job Application Tracker prototype designed to help students and job seekers organise their job application information.

## Project Modules
1. Dashboard
2. Add Application
3. My Applications
4. Application Details
5. Interview Tracker
6. Company Directory
7. Career Resources
8. About Project

## Technologies Used
- HTML5
- Visual Studio Code
- GitHub

## Features
- Eight interconnected HTML webpages
- Job application entry form
- Application and interview tables
- Company information and career links
- Career learning resources
- Semantic HTML structure

## Current Limitations
This is a static HTML prototype. Forms do not permanently save information, and dashboard statistics do not update automatically.

## Future Enhancements
Additional technologies may be explored to support data storage, dynamic updates and more interactive features.
