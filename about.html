About CareerTrack

Project Introduction

CareerTrack is a Job Application Tracker designed to help students and job seekers organise their job applications and interview preparation.

Project Objectives

  • Organise job application information.
  • Track application statuses.
  • Manage interview schedules.
  • Maintain company information.
  • Provide useful career resources.

Main Features

  1. Application Dashboard
  2. Add Job Applications
  3. View Application Records
  4. Application Details
  5. Interview Tracker
  6. Company Directory
  7. Career Resources

Technologies Used

  • HTML5
  • Visual Studio Code
  • Web Browser
  • GitHub for project sharing

Project Limitations

This version is a static HTML prototype. Application information and form submissions are not stored permanently.

Future Enhancements

  • Add CSS for improved appearance.
  • Add JavaScript for interactive features.
  • Add a database to store applications.
  • Add user login and registration.
